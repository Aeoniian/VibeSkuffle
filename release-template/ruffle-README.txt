Modified Mugetsu (VibeSkuffle edition)
======================================

This Mugetsu.exe is a MODIFIED build of Mugetsu v1.5.1 (https://github.com/mugetsu-aqw/mugetsu), changed
in 2026-10 for VibeSkuffle: it adds the named-pipe bridge VibeSkuffle uses to control the game, web request
timeouts, per-window logs and crash reports. It is not an official Mugetsu release; please don't
report problems with it to the Mugetsu author.

Don't replace it with the official Mugetsu: VibeSkuffle can't talk to the official build.
